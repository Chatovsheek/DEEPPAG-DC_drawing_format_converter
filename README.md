# DEEP конвертер чертежей
**DEEPPAG-DC drawing format converter**

Один HTML-файл. Работает без интернета, файлы никуда не загружаются.

## Как пользоваться
1. Откройте файл в браузере (Chrome, Edge, Firefox).
2. Перетащите чертёж в рамку, или нажмите на неё, или вставьте файл/текст из буфера (Ctrl+V). Формат определяется сам, по содержимому, а не по имени файла.
3. Выберите, во что конвертировать, и качество.
4. Нажмите «Конвертировать и скачать».

## Что поддерживается (этап 1)
| Из \ В | DXF | SVG | PDF | PNG | JSON |
|---|---|---|---|---|---|
| **DXF** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **SVG** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **JSON эскизника** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **PNG / JPG** | ❌ | ❌ | ✅ | ✅ | ❌ |
| **PDF** | ❌ | ❌ | ❌ | ❌ | ❌ |

Следующие этапы: PDF на входе (из PDF, сделанных в CAD, можно будет извлечь линии) и PNG/JPG в линии (трассировка).

JSON означает файл проекта нашего эскизника DEEP_PAG.

## Качество и цвета
- **Качество** (Черновик / Обычное / Высокое) задаёт размер картинки для PNG и PDF: 1500 / 3000 / 6000 px по большей стороне.
- **Цвет линий:** «Чёрные на белом» удобно для печати; «Как в файле» сохраняет цвета (белые линии всё равно рисуются чёрными, иначе не видны на белом).

## ⚠️ Важные предупреждения
**Общие**
- PDF создаётся **картинкой** (JPEG), а не вектором. Для точной печати берите «Высокое» качество, а для вектора формат SVG или DXF.
- Конвертер переносит линии, окружности, дуги, ломаные и текст. Остальное в файле может быть пропущено; программа показывает, что именно.
- Всегда проверяйте результат глазами: превью показывается сразу после загрузки.

**DXF на входе**
- Читаются текстовые DXF (не двоичные). Поддержаны: линии, окружности, дуги, ломаные (с дугами), эллипсы, текст, блоки, размеры, слои и цвета.
- **Не переносятся:** штриховки (HATCH), заливки (SOLID), изображения, 3D-грани, выноски и т. п. Они перечисляются в предупреждении.
- Сплайны упрощаются до ломаных.
- Толщина линий из DXF не учитывается; типы линий определяются по имени (штриховая, осевая и т. д.).
- Если в файле не указаны единицы, они считаются миллиметрами.
- Читаются только объекты пространства модели, листы компоновки пропускаются.
- Выравнивание текста учитывается приблизительно.
- **DWG не поддерживается** (закрытый формат). Сначала преобразуйте его в DXF бесплатными ODA File Converter, LibreCAD или FreeCAD.

**DXF на выходе**
- Формат совместим с AutoCAD R12, поэтому читается почти везде (КОМПАС, LibreCAD, FreeCAD, QCAD).
- Толщина линий не сохраняется, цвета приводятся к основным 7, штриховые линии записываются сплошными.
- Кириллица записывается в кодировке Windows-1251; в совсем старых программах без этой кодовой страницы текст может отображаться неверно.

**SVG на входе**
- Поддержаны линии, прямоугольники, окружности, эллипсы, ломаные, пути (включая кривые и дуги) и текст; преобразования (сдвиг, поворот, масштаб) учитываются.
- Заливки не переносятся: фигуры передаются контурами. Градиенты, фильтры, картинки и стили через `<style>` не поддерживаются.
- Если в SVG нет размера в мм/см/дюймах, 1 единица принимается за 1 пиксель (0,2646 мм).

**SVG на выходе**
- Размер записывается в миллиметрах; фон прозрачный. Кривые из SVG на входе сохраняются как ломаные.

**JSON эскизника**
- Из эскизника: рамка и штамп, а также подписи размеров, созданные автоматически, не переносятся (только нарисованные размерные линии). Ластик пропускается.
- В эскизник: дуги, ломаные и сплайны превращаются в короткие отрезки (в эскизнике нет таких объектов). Цвета чёрного заменяются белыми (тёмный фон эскизника). Чертёж центруется.

**PNG / JPG**
- Из картинки получаются только PNG и PDF (с изменением размера). Превращение картинки в линии (DXF, SVG, JSON) будет позже; это трассировка, результат будет зависеть от качества исходной картинки.

**PDF на входе** пока не поддерживается.
